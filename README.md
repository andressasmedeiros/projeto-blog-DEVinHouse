# 📝 Projeto Blog - DEVinHouse

Este é um projeto desenvolvido durante o curso **Clamed v3 - DEVInHouse**, com o objetivo de criar uma aplicação simples de blog onde os usuários podem criar posts e armazená-los localmente no navegador.

---

## 🚀 Funcionalidades

- **Criação de Posts**: O usuário pode criar posts com título e conteúdo.
- **Armazenamento Local**: Os posts são armazenados no `localStorage` do navegador, permitindo persistência entre sessões.
- **Exclusão de Posts**: Cada post possui um botão de exclusão, permitindo que o usuário remova posts indesejados.

---

## 📦 Tecnologias Utilizadas

- **HTML5**: Estruturação da página.
- **CSS3**: Estilização da interface.
- **JavaScript**: Lógica de criação, armazenamento e exclusão de posts.
- **localStorage**: Armazenamento dos posts no navegador.

---

## 🛠️ Instalação e Execução

1. Clone este repositório:
   ```bash
   git clone https://github.com/andressasmedeiros/projeto-blog-DEVinHouse.git
   ```

2. Navegue até o diretório do projeto:
   ```bash
   cd projeto-blog-DEVinHouse
   ```

3. Abra o arquivo `index.html` em seu navegador preferido.
